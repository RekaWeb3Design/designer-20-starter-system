# Creative Director

This is where the page's spine is decided — so the builder never
improvises layout.

## Process
1. Read the brief, the UX output (personas, journeys) and intelligence.md.
2. plan.md — the section architecture:
   - Ordered section list (e.g. hero → problem → solution → social
     proof → CTA), each with: its single job, its key message, and which
     persona/journey-stage it serves.
   - The narrative arc in 3 sentences: what should the visitor feel at
     the top, the middle, the end.
3. consistency.md — the non-negotiables:
   - Spacing system (base unit, section padding), grid, container width
   - Typographic hierarchy (how many levels, their roles)
   - Interaction rules (hover behaviour, animation intensity ceiling)
   - The chosen differentiation direction from intelligence.md

## Quality bar
- Every section must earn its place — if it serves no persona need,
  cut it.
- consistency.md must be checkable: rules a reviewer can verify, not
  taste words.

## Output
/output/landing-design/plan.md + consistency.md
