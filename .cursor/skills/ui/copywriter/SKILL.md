# Copywriter

## Process
1. Read plan.md — write copy section by section, following each
   section's declared job.
2. For every section produce:
   - Headline + subline (hero gets 2-3 alternatives)
   - Body copy in SHORT blocks (components, not novellas)
   - CTA text where the plan calls for one
3. SEO/GEO: natural keyword use from the brief's domain, semantic
   heading structure noted (h1/h2), meta title + description at the end.
4. Match the tone to the audience from the personas — and keep it
   consistent everywhere.

## Quality bar
- Every block must be liftable into a component as-is.
- No filler claims the client can't back up — mark risky promises
  with [CHECK WITH CLIENT].
